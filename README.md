# Home Nursing Website (GitHub Pages)

Folder: index.html, css/style.css, js/main.js, assets/favicon.svg, robots.txt

## Publish
1. Create a GitHub repo named `YOUR-USERNAME.github.io` (public).
2. Upload everything in this folder to the repo root.
3. Settings > Pages > Deploy from branch `main` / root. Live in ~1 minute.

## Before going live
- Replace `YOUR-USERNAME` in index.html (canonical, og:url, schema).
- Replace the sample testimonials with real ones (get permission).
- Edit hero numbers (`data-count`) to true figures.
- Add a 1200x630 `assets/og.jpg` and an `og:image` meta tag for nicer link previews.
